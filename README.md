# 🩺 PulseCare – Health & Hygiene Portal

PulseCare is an interactive **Health & Hygiene Portal** designed to provide users with useful information about personal hygiene, common diseases, BMI, and basic first-aid care in one easy-to-use platform.

The website provides an interactive and user-friendly interface with multiple health-related modules, search functionality, theme switching, and interactive health tools.

---

## 📌 Project Overview

**PulseCare** aims to spread awareness about everyday health, hygiene, disease prevention, and emergency care.

The platform contains four major modules:

* 🧼 **Personal Hygiene**
* 🦠 **Diseases & Their Prevention/Care**
* ⚖️ **BMI Calculator**
* 🩹 **First Aid Guide**

The website is designed with a responsive interface and interactive components to make health information easier to explore.

---

## ✨ Features

### 🧼 1. Personal Hygiene

The Personal Hygiene section provides information about maintaining cleanliness and healthy daily habits.

It includes:

* Why personal hygiene is important
* Body hygiene guidelines
* Oral hygiene
* Hair and nail care
* Personal grooming
* Clean clothing and skin-care practices
* Prevention of germ spread

---

### 🦠 2. Diseases & Their Care

The Diseases section provides information about common health conditions.

Currently covered:

* Common Cold & Flu
* Dengue Fever
* Obesity
* Anemia

For each condition, the website provides relevant information such as:

* Symptoms
* Prevention
* Treatment/care
* Risk factors
* Health and safety warnings where applicable

> **Note:** PulseCare is an educational awareness platform and should not replace professional medical diagnosis or treatment.

---

### ⚖️ 3. Interactive BMI Calculator

The website includes an interactive BMI calculator.

Users can:

1. Enter their height.
2. Enter their weight.
3. Calculate their BMI.
4. View their BMI score.
5. View the corresponding BMI category.

The calculator supports different height input units through its unit-selection interface.

---

### 🩹 4. First Aid Guide

The project also includes a quick-access first-aid section intended to provide basic emergency-care information and actionable protocols.

---

## 🔍 Search Functionality

PulseCare includes a global search bar that allows users to search through health-related content such as:

* Hygiene
* Diseases
* Symptoms
* First-aid information

Search results are displayed through an interactive results interface.

---

## 🌙 Dark & Light Mode

The website provides a theme-switching feature that allows users to switch between:

* 🌙 Dark Mode

This improves accessibility and provides users with a more comfortable viewing experience.

## 🚀 How to Run the Project

### Method 1 – Directly in Browser

1. Download or clone the project.
2. Keep all project files in the same folder.
3. Open `index.html` in a web browser.
4. The PulseCare website will load.

### Method 2 – Using VS Code

1. Open the project folder in **Visual Studio Code**.
2. Make sure `index.html`, `styles.css`, and `app.js` are in the correct location.
3. Open `index.html`.
4. Run the project using a browser or the **Live Server** extension.
